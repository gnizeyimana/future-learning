
# Future Skills Learning Center

## 1. Project Description
Future Skills Learning Center is an educational website designed to help students develop computer skills, digital knowledge, creativity, and innovation.

The website provides information about the learning center, available courses, student registration, and contact information.

## 2. Project Objectives
- Help students develop digital skills.
- Provide information about available courses.
- Allow students to register for learning programs.
- Encourage creativity and innovation.
- Make learning technology easier and more accessible.

## 3. Website Pages
- **Home:** Introduces the learning center.
- **About:** Explains the center and its mission.
- **Courses:** Displays available courses.
- **Register:** Provides a student registration form.
- **Contact:** Provides contact information and a message form.

## 4. Technologies Used
- HTML5
- Images and graphics
- Audio and video media

## 6. Media and Resources
- Images are stored in the images folder.
- Graphics are stored in the graphics folder.
- Audio and video files are stored in the media folder.

## 7. How to Run the Website
1. Open the project folder in Visual Studio Code.
2. Open index.html.
3. Run the file using a web browser.
4. Navigate through the website using the navigation links.

## 8. Conclusion
Future Skills Learning Center aims to support students in developing useful digital skills and preparing for future opportunities in technology.
